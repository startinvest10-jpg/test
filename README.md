# AgentSellerAI — редизайн лендинга

Одностраничный сайт в одном файле `index.html`: без сборки и без зависимостей.
Чтобы посмотреть, откройте файл в браузере.

## Что заменить перед публикацией
- **Отзывы.** Сейчас там заглушки. Замените их на реальные отзывы клиентов в массиве `reviews` внутри `<script>`.
- **Цены.** Сейчас стоят примерные. Настоящие задаются в массиве `PLANS` внутри `<script>`.
- **Ссылки «Learn more», «Get started».** Сейчас они ведут на `#`. Подставьте нужные адреса.
- **Цифры в демо-дашборде и чате.** Это иллюстрация, при желании поменяйте их.
